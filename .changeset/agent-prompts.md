`AGENT_PROMPTS`, `AGENT_PROMPTS_HEADING` and `AGENT_PROMPTS_LEDE`: three
"paste this into your agent" prompts — set up my computer, add BYOLLM to my
site, run my own relay — so every surface shows the same words. The source is
`AGENT-PROMPTS.md`; the README and byo-llm.com strips are generated from it,
and a test holds each `byollm` command to `byollm --help`, each docs anchor to
the docs and each package to the ones this repository publishes.
