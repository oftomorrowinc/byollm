# Code of conduct

**Be honest, be kind, argue about the work.**

This is a small project run by people who would rather read a blunt, correct
issue than a polite, vague one. Disagree with a decision, a design, or a line
of code as hard as you like — with the reasoning attached. What is not welcome
here is contempt for people: insults, harassment, slurs, dismissing somebody
for who they are rather than what they wrote, or following a disagreement out
of the thread into their inbox. Those get one warning, and then they get
removed — from the thread, and if it continues, from the project.

That applies everywhere the project is: issues, pull requests, discussions,
and anywhere else you are speaking as a contributor.

## Reporting

If somebody has crossed that line, write to support@byollm.cloud. You will
get a reply from a person, and what you report stays between you and the
maintainers unless you say otherwise.

Security problems are a different door — [`SECURITY.md`](SECURITY.md) —
and nothing about them belongs in a public issue.

## Why this is short

A long code of conduct is a list of things somebody once had to be told. We
would rather say the principle once and hold to it.
