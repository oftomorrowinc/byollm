# Open source first

The protocol in this repository is the trunk. A commitment, stated
plainly so it can be held against us:

**Every protocol change lands in this open spec before — or in
parallel with — any deployment that uses it. Including ours.**

There is no private dialect. If a hosted service, a commercial
offering, or anyone's production system needs the protocol to do
something new, the capability appears here first, as a spec change
with conformance coverage, speakable by any implementation. A daemon
or server that passes the conformance kit is a full citizen of the
network — there is no capability reserved for infrastructure we run.

What this does *not* promise: that operational infrastructure built
around the protocol is open source (some of ours will not be), or
that every proposal is accepted (the spec evolves slowly, on
purpose). It promises that the protocol itself never forks into a
public version and a real one.
