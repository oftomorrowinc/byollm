# 0.1.0-alpha.3

*Recovered from the READMEs it was prepended to — B340. Nothing retired these, so they had reached 322 lines above `# BYOLLM` and 103–129 above each package's own title, and npm served them as the opening of every 0.1.0 tarball.*

*Written more than one way for different audiences — the root README carried the product summary and a package its own. Both kept; neither chosen over the other.*

## As written in packages/daemon

> **`alpha.3` is a breaking change.** A config naming `openai-http` with a
> remote base URL and an offer scope wider than `private` is narrowed to `private`
> until you acknowledge the spend and set a daily ceiling:
> `byollm offer <backend> public --cap <cents>`. Local base URLs are
> unaffected. `byollm backends` shows the cost class per route.
## As written in packages/protocol

> **`alpha.3` is a breaking change.** `BackendDescriptor.account` is gone —
> read `cost` (`free` / `metered` / `subscription`) instead. Four new MUSTs
> come with it; see `byollm_007`.
